# ผลตรวจ OTT — 17 ตุลาคม 2026

ตรวจทุกรายการใน 18 หมวดที่เคยพบปัญหา: รอบแรก 39,715 รายการ และตรวจย้ำหลังแก้ไข 1,915 รายการ รายการกีฬาเปลี่ยนตามเวลาตรวจ จึงเก็บหลักฐานหลายรุ่นของรายการไว้ ไม่ถือว่ารายการที่หายจาก catalog เป็นหลักฐานว่าสัญญาณหมดอายุ

รายงานแยกรายการพร้อมเวลาและสถานะ HTTP อยู่ที่ `reports/ott-audit/2026-10-17.json` (หลักฐาน local ไม่ถูกเผยแพร่เป็นไฟล์สาธารณะ) มี ID, หมวด, ผลตอบกลับ, ผลเปรียบเทียบกับต้นทาง และประวัติการทดสอบภาพ โดยไม่เก็บ URL ที่มีสิทธิ์รับชม โทเคน หรือกุญแจ DRM

## สิ่งที่แก้และยืนยันได้

- Proxy ตรวจเนื้อหาจริงก่อน rewrite: วิดีโอที่ต้นทางติดป้ายเป็น playlist จะถูกส่งเป็นไบต์เดิม ไม่ถูกแปลงเป็นข้อความ
- DASH รับ CDN ข้ามโดเมนจาก manifest ที่โหลดด้วย URL ลงลายเซ็น แล้วออก context ลงลายเซ็นใหม่ให้เฉพาะโดเมนที่ manifest ระบุ
- Live manifest ไม่ถูก cache ค้าง 30 วินาที
- Parser รองรับ ClearKey หลายคู่คั่นด้วย comma ตามข้อมูลที่ playlist ให้มา ช่อง WILLOW ยืนยันเล่นผ่าน React player แล้ว
- เครื่องเล่นแสดงข้อผิดพลาดแยกตามหลักฐาน เช่น HTTP 404, การปฏิเสธสิทธิ์, ปัญหา proxy และ DRM

ผลทดสอบภาพหลังแก้: `Sport Mpd` เล่นครบ 3/3 ช่อง, `Sport MPD` เล่นได้ 29 จาก 31 ช่องที่โหลด manifest สำเร็จ (ทั้งหมด 36 ช่อง อีก 5 ช่องต้นทาง/เส้นทางเชื่อมต่อล้มเหลว), ชุด 52 รายการใน “ห้องขอมา” ที่เคยเล่นไม่ได้เพราะไฟล์ถูกอ่านผิดชนิด ยืนยันภาพและเวลาเล่นเดินครบ 52/52 รายการ

ทดสอบหน้า React จริงเพิ่มเติม 10 รายการ: ผ่าน 8 รายการ เหลือ GO3 SPORT 2/3 และยืนยันว่ากดการ์ดแล้วเปิด overlay เต็มจอโดย URL ยังอยู่หน้าหมวดเดิม

## ขอบเขตการยืนยัน

รอบแรกเป็นการตรวจ HTTP/manifest/segment ไม่ได้เปิดภาพครบ 39,715 รายการ รอบย้ำอ่าน HLS manifest เต็ม ตรวจ segment แรก/ท้ายและ AES key พร้อมเทียบต้นทางเมื่อ proxy ล้มเหลว โดยตรวจครบทุกช่องในหมวดเล็กที่ยังมีรายการ และตรวจรายการล้มเหลวในหมวด VOD ใหญ่ ส่วน HTTP 521 ที่ตรวจไว้เป็นรายรายการแล้ว ใช้การตรวจซ้ำแบบกระจาย 21 รายการเพื่อยืนยันว่าปัญหาต้นทางยังเกิดอยู่

การมี manifest หรือ segment ไม่ยืนยันว่าถอดรหัสในเบราว์เซอร์ได้ หลักฐานภาพจริงเก็บแยกจากผล HTTP ผลทั้งหมดเป็นสถานะ ณ เวลาตรวจ ไม่รับรองว่าสตรีมสดจะพร้อมตลอดเวลา
