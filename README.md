# Entertainment Complex

เว็บ React สำหรับเลือกดูหนัง ทีวีสด และกีฬาสดจาก `Doowiseplay-movies.csv` และ `Doowiseplay-movies.m3u` โดยไม่มีโฆษณาในตัวผลิตภัณฑ์

## ประสบการณ์ใช้งาน

- หน้าแรกแสดงหนังที่เพิ่มใหม่ล่าสุดจากสัญญาณอัปเดตของต้นทาง
- หน้าหมวดแยกเป็นหนัง ทีวีสด และกีฬาสด พร้อมค้นหา ตัวกรอง และ pagination
- หน้ารายละเอียดแสดงข้อมูลของรายการก่อนเข้าสู่เครื่องเล่น
- หน้าเครื่องเล่นรองรับ HLS, DASH และไฟล์วิดีโอผ่าน secure proxy
- URL ของทุกหน้าสามารถเปิดหรือแชร์โดยตรงได้

## เริ่มใช้งาน

```powershell
npm install
npm run build
npm start
```

จากนั้นเปิด `http://127.0.0.1:4173`

`npm run dev` และ `npm start` จะ sync catalog ก่อนเปิดเซิร์ฟเวอร์ เพื่อหมุน token ทีวีและโหลดตารางกีฬาปัจจุบัน ส่วน Vite จะ proxy `/api/sports` และ `/api/update-catalog` ไปยัง backend production จึงไม่อ่านซอร์สของ Vercel Function เป็น HLS manifest สามารถเปลี่ยนปลายทางได้ด้วย `VITE_DEV_BACKEND_ORIGIN`

## โครงสร้าง

- React + Vite สำหรับ UI แบบหลายเส้นทาง
- Express API สำหรับค้นหารายการหนัง
- Media proxy แบบ URL ลงลายเซ็นภายในโปรเซส เพื่อส่ง Referer/User-Agent ตามไฟล์เดิมและ rewrite HLS manifest
- Proxy รับเฉพาะรายการใน catalog และ resource URL ที่เซิร์ฟเวอร์สร้างลายเซ็นให้ ไม่ได้เปิดเป็น arbitrary URL proxy
- ตรวจ metadata ของทั้ง 4 แหล่งทุก 15 นาที ดาวน์โหลดเฉพาะแหล่งที่เปลี่ยน เพิ่มรายการใหม่ และตัดรายการซ้ำแบบอัตโนมัติ (ไม่ลบรายการเดิม)
- หน้า React ตรวจ version ของ catalog และอัปเดตรายการโดยไม่ต้องรีเฟรชหน้า
- ขั้นตอน sync เก็บ `recent` IDs และ `discoveredAt` เพื่อให้หน้าแรกแสดงรายการที่เพิ่งเพิ่มจากต้นทางได้จริง
- ตารางกีฬาจะแสดงเฉพาะรายการปัจจุบันและล่วงหน้า 48 ชั่วโมง พร้อมระบุ `sportsHealth` เมื่อบาง feed ต้องใช้ข้อมูลสำรอง

ข้อมูลต้นทางและสถานะการซิงก์อยู่ในโฟลเดอร์ `data/` ส่วนรหัสสมาชิกอยู่ใน `.env.local` ซึ่งถูกกันออกจาก Git แล้ว

## ตั้งค่าการซิงก์

```dotenv
DOOWISE_MEMBER_ID=รหัสสมาชิก
DOOWISE_SYNC_INTERVAL_MINUTES=15
```

เซิร์ฟเวอร์ตรวจครั้งแรกทันทีที่เปิด จากนั้นตรวจซ้ำตามช่วงเวลาที่กำหนด การซิงก์ทำงานเฉพาะตอนที่ `npm start` หรือ `npm run dev` ยังเปิดอยู่
